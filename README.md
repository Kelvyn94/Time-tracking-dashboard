Time Tracking Dashboard
A responsive time tracking dashboard built with HTML, CSS, and JavaScript. This project demonstrates professional frontend development practices including CSS custom properties, fluid typography with clamp(), and dynamic data rendering.

Features
Responsive Design - Mobile-first approach that adapts seamlessly from 320px to large screens

Interactive Period Switching - Toggle between Daily, Weekly, and Monthly views

Dynamic Data Rendering - Activity cards generated from JSON data

Accessible - Semantic HTML with ARIA attributes and keyboard navigation

Hover States - Interactive feedback on all clickable elements

Technologies Used
HTML5 - Semantic markup structure

CSS3 - Custom properties (var()), clamp() for fluid values, CSS Grid, Flexbox, relative units (rem, %)

JavaScript - DOM manipulation, event handling, array methods (.map(), .forEach())

Key Concepts Demonstrated
CSS custom properties for theming and maintainability

Fluid typography and spacing using clamp()

Mobile-first responsive design with media queries

JavaScript data-driven rendering

Accessibility best practices

Setup
Clone the repository

Open index.html in your browser

No build tools required - pure HTML/CSS/JS
